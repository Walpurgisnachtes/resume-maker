AI Prompt

Convert the resume or career notes I provide into Resume Maker import text.

If I haven't supplied any source material, ask me to paste it. Once I supply it, return only the import text, with no Markdown fences, preamble, or commentary. Use only facts supported by my material. Do not invent contact details, dates, qualifications, skills, or achievements. The values below are examples, not facts about me.

Use one key: value per line and the exact keys shown below. Omit unsupported fields and empty sections. Start each degree, skills group, job, or project with a new matching bracketed header. Every education, experience, or project block must have a title; every skills block must have at least one skill. Repeat role, link, introduction, skill, or highlight on separate lines for multiple values. Keep each value on a single line.
